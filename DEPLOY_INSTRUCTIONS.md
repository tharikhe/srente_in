# 🚀 How to Deploy to Vercel (First Version)

Since this is the first deployment, you'll need to authenticate. Follow these simple steps:

1.  **Open your terminal** in VS Code.
2.  Run this command:
    ```bash
    npx vercel
    ```
3.  **If asked to log in:**
    *   Select "Continue with GitHub" (or Email).
    *   It will open your browser.
    *   Click "Verify" / "Login".
    *   Go back to the terminal.

4.  **Answer the prompts** (Press Enter for defaults):
    *   `Set up and deploy “...\seretech”?` → **y**
    *   `Which scope do you want to deploy to?` → **(Select your name)**
    *   `Link to existing project?` → **n**
    *   `What’s your project’s name?` → **seretech** (Press Enter)
    *   `In which directory is your code located?` → **./** (Press Enter)
    *   `Want to modify these settings?` → **n**

5.  **Wait for it to upload...**
    *   It will take about 1-2 minutes.
    *   It will show `Production: https://seretech-xxxx.vercel.app [copied to clipboard]`

6.  **Done!** Send that link to your client.
